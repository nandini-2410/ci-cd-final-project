# CI/CD Final Project

## Project Overview

This project demonstrates a Continuous Integration and Continuous Delivery (CI/CD) pipeline using GitHub Actions, Tekton, and OpenShift.

## Objectives

- Automate code linting and unit testing using GitHub Actions.
- Define CI/CD tasks using Tekton.
- Build and deploy the application through an OpenShift Pipeline.
- Validate the pipeline execution and application deployment.

## Technologies Used

- GitHub
- GitHub Actions
- Tekton Pipelines
- OpenShift
- Python or JavaScript, depending on the selected lab option
